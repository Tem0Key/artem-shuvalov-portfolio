# Company logo assets

Source images were supplied by the portfolio owner. Background extraction used the built-in image generation/editing tool with transparent output. The selected PNGs retain alpha and are resized to 256px for the website. Photographs were not generated or retouched; they were resized and encoded for web delivery.

## Sber prompt

Use case: background-extraction. Edit target: the supplied Sber logo. Remove ONLY the flat white exterior/background and white negative space; make these truly transparent with alpha. Preserve the exact original cyan-blue-to-lime-green circular ring and solid green check mark, their geometry, proportions, gradients and colors. Center the full mark with minimal transparent margin. No redesign, no added text, no shadows, no white rectangle, no checkerboard. Output a clean transparent PNG asset for a company logo in a portfolio.

## STC prompt

Use case: background-extraction. Edit target: the supplied STC (СТЦ) navy shield logo. Remove ONLY the white background OUTSIDE the outer navy shield outline to real transparent alpha. Preserve the shield exactly including navy fill, white lightning bolt, white horizontal band with the exact navy Cyrillic letters СТЦ, white inset border and all geometry. Interior whites belong to the logo and MUST remain opaque. Center full shield with minimal transparent margin. No redesign, no new elements, no shadows, no checkerboard. Output a clean transparent PNG asset for a company logo in a portfolio.
